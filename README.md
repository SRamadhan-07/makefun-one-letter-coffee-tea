A Python program — standard library only, no network — that writes exactly one letter to /output/entry.txt: A, for coffee — the pick of a sender whose loyalty coffee earned by staying at 3 a.m. The competition's gate is UTF-8 text of exactly 1 character, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
